The full prioritised, citation-backed report ("What Parakkat Jewels' HR/Payroll Software Legally Must Have — and What It Should Have") is saved at:

- Markdown source: `docs/research/hr-payroll-compliance-report.md` (repo root of parakkat-hr-software)
- Published Artifact (designed HTML version, same content): https://claude.ai/code/artifact/38332ead-d280-434c-ac3f-910b8dbac903

Structure: Part A = legally mandatory statutory gaps (EPF, ESI, Kerala Professional Tax, TDS, Gratuity, Bonus Act, Kerala Shops Act, Maternity Benefit Act, POSH Act, Labour Codes 2020 status, Kerala minimum wages, statutory registers/returns). Part B = table-stakes features vs. 6 Indian HR SaaS competitors (greytHR, Keka, Zoho People/Payroll, Darwinbox, RazorpayX Payroll, Kredily) with pricing. Part C = high-value retail-specific features (shift rostering, sales commission, festival attendance edge cases, ESS app, WhatsApp notifications, document retention, F&F settlement automation, loan/advance management).

See [[project-parakkat-compliance-findings]] for the key non-obvious takeaways without re-reading the full report, and [[project-parakkat-business-structure]] for the underlying business context.
